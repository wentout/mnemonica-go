# Conformance matrix — mnemonica for Go

Status values: `ported`, `adapted` (same meaning, different shape — note says how),
`N/A` (cannot exist in Go — note says why), `open` (not yet implemented).

JS sources: the mnemonica core repository (its `README.md`, `FOR_HUMANS.md`,
`.ai/PROTOTYPE-CHAIN.md`, `.ai/test-map.md`).
